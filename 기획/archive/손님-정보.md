## 1. 손님 1명 = 무엇으로 이루어지나 (기존 시스템 매핑)

| 층위 | 담는 곳 | 필드 / 열 |
|---|---|---|
| 정체성·외형 | `NpcData` (SO, NPC당 1개, `id` 1~60) | `displayName`/`displayNameKo`, 초상화(neutral/angry/back/side), `modelPrefab`(미사용) |
| 게임 로직 (플레이어에게 안 보임) | `NpcData` | `isSleepwalker`(내부 정답), `visitorOnly`, `refusesDawnKnock`, `stayNights`, `allowsMorningCleaning`, `idCard{name,birthDate,photo,forged}` |
| 대사 | `sample.csv` → `DialogueDatabase` | `npcId, situation(Reception/Dawn), day(0=공통), role(Greeting/Question/Node), nodeKey, label_ko, expression, text_ko, goto, outcome` |
| 일차 편성 | `CampaignData` / `DayData` | `eveningGuests`(그날 오는 순서), `nightNews` |
| 플레이어 판단 | `GuestManager.Verdict {None, Approved, Rejected, Killed}` | `isSleepwalker` 와의 괴리 = 오판 |

**3층 판별** (위협 문서 3.2) — 이 문서의 각 카드는 세 층에 신호를 하나씩 배분한다:

| 층 | 시점 | 이 카드의 칸 |
|---|---|---|
| 1. 서류 | 저녁 접객 | **서류 특이사항** (신분증 위조 / 예약 명단 불일치 / 진술↔서류 모순) — 인간의 거짓말 |
| 2. 구별법·대화 | 저녁 접객 | **저녁에 새는 신호** (약함, 오판 유발) + TV 구별법과의 충돌 |
| 3. 야간 관찰 | 새벽 | **야간 신호** (문틈·CCTV·방 상태) — 가장 강하지만 이미 안에 있음 |

`isSleepwalker`(진짜 감염인지)는 **개별 손님 고정값이 아니라 일차 편성에서 결정**한다 — 같은 컨셉이 어느 날은 감염, 어느 날은 겁먹은 무고한 사람. 이 문서는 "감염 톤이 강한가/약한가"만 표시(오판 후보 = 톤은 강한데 실제론 무고).

## 2. 접객(저녁) 공통 골격

`sample.csv` 의 id 1~5 가 확립한 구조. 신규 손님도 이 뼈대에 살을 붙인다.

```
[Greeting]  여러 줄 인사 — 여기에 요청사항(숙박일수/하우스키핑)이 자연스럽게 섞임
[Question]  플레이어가 고르는 질문 버튼들:
   name / id   이름·신분증 요구        → 서류 층
   purpose     목적·행선지·동행 여부
   stay        며칠 묵나 → [선불 받기 / 후불 / 2배] 분기   (doc/0137·0140, 기본 $35·박)
   clean       하우스키핑 → [매일 아침 / 부를 때만] 분기   (allowsMorningCleaning)
   need        필요한 것 (담요·식사 등, 인간적 정보)
   reject      돌려보내기 → 조르는 손님은 reject_insist 로 여러 번 → reject_final(outcome=Rejected)
[Node]  checkin / checkin_paid  = 승인 시 한마디 → 주인방을 나감
        reject_final            = outcome=Rejected → 퇴장(또는 점프스케어)
```

승인 후: 모니터에서 방 배정 → 열쇠 줍기 → 손님 클릭 → 손님이 배정 방으로 (`doc/0104`·`doc/0118`).

**새벽(Dawn):** `refusesDawnKnock=false` 면 Greeting + 관찰 질문(`noise`/`night`/`seen`/`halls`/`leaving`), `true` 면 `refuse` 노드 한 마디 후 문 안 열림.

### 각 손님 카드가 채우는 칸

1. **외형 / 평범·이상 행동 / 공포 포인트** — 원 표
2. **접객 톤** — 체크인 첫인상, 말투(정중/무뚝뚝/불안/오만), `expression` 어디서 `Angry`
3. **요청** — `stayNights` · 선불/후불 태도 · 하우스키핑(`allowsMorningCleaning`) · 객실 요청(조용한 방/길에서 먼 방/특정 층)
4. **서류 특이사항 (층1)** — `idCard` 이름/생년, `forged`, 예약 명단 대조
5. **저녁에 새는 신호 (층2)** — 접객 중 드러나는 작은 이상 (약함)
6. **야간 신호 (층3)** — 문틈·CCTV·방 상태
7. **첫 단서** — 무엇을, 어느 시간대/태스크에서 (원 표 + 배치)
8. **데이터 플래그(제안)** — `stayNights` / `allowsMorningCleaning` / `refusesDawnKnock` / `visitorOnly` / `idCard.forged`. `isSleepwalker` 는 일차 편성 담당
9. **배치** — 초반(1~3일, 미묘) / 중반(4~8, 노골) / 후반(9+, 명백)

## 4. 신규 손님 컨셉 20

배치 범례: 초 = Day 1~3, 중 = Day 4~8, 후 = Day 9+.

### #1 출장 회사원
- **외형** 30~40대 남성, 정장, 서류가방
- **접객 톤** 지친 척 정중, 효율적. 늦은 밤 체크인. "하룻밤이면 됩니다, 일 끝나면 새벽에 나갈 거라"
- **요청** 1박 / 법인카드 선불 선호 / 하우스키핑 거부("서류가 많아서") / 조용한 방
- **서류 (층1)** 사원증 제시 — 회사명 A. 나중 단서의 명함은 회사 B. `idCard.forged` 는 미묘하게(이름은 맞고 소속이 틀림)
- **저녁 신호 (층2)** 대화 중 시계·휴대폰 반복 확인, "일행이 곧 도착한다"(오지 않음)
- **야간 신호 (층3)** 방에 없는 사람과 계속 통화하는 소리
- **첫 단서** 쓰레기통의 **타 회사 명함** — 체크아웃 아침 청소(SYS-02)
- **플래그** stay 1, clean 거부, dawnKnock 열어줌
- **배치** 초~중 / 감염 톤 약함(오판 후보)

### #2 장거리 트럭기사
- **외형** 40~50대 남성, 작업복, 낡은 재킷
- **접객 톤** 피곤, 짧게. "트럭 댈 자리만 있으면 됩니다"
- **요청** 1박 / 후불 / 하우스키핑 무관 / 주차장 잘 보이는 방
- **서류 (층1)** 운전면허 + 화물 운송장. 운송장 목적지가 이 지역이 아님
- **저녁 신호 (층2)** 주차장 쪽을 자꾸 돌아봄, 트럭 화물 얘기를 피함
- **야간 신호 (층3)** 새벽마다 방에서 나와 주차장을 응시. CCTV엔 트럭이 있는데 **운전석이 비어 있음**
- **첫 단서** 방 바닥의 **진흙 발자국** — 다음날 아침 청소
- **플래그** stay 1, clean 허용, dawnKnock 열어줌
- **배치** 초~중 / 감염 톤 중간

### #3 혼자 여행 온 여성  *(기존 id 4 를 이 컨셉으로 확정)*
- **외형** 20~30대, 야상, 청바지, 배낭
- **접객 톤** 방어적, 최소한의 말. "길에서 먼 방으로요. 잠귀가 밝아서"
- **요청** 하루씩 결제 / 하우스키핑 거부 / 길·복도에서 먼 방, 커튼 잘 되는 방
- **서류 (층1)** 정상. 단 예약자명과 본인이 대는 이름이 다름("친구 이름으로 잡았어요")
- **저녁 신호 (층2)** 문 쪽을 계속 봄. "저 말고 다른 손님 있어요?" "누가 절 찾으면 없다고 해주세요"
- **야간 신호 (층3)** 커튼 반복 확인, 문 여러 번 잠금. 새벽 노크에 문 안 엶(`refuse`)
- **첫 단서** 복도 CCTV에 **그녀 뒤에 서 있는 사람의 실루엣**
- **플래그** stay 1, clean 거부, **refusesDawnKnock**
- **배치** 초~중 / 감염 톤 약함 (진짜 스토커일 수도 = 무고한데 규칙엔 걸림)

### #4 중년 부부
- **외형** 50~60대, 단정한 여행복 (남편만 카운터에)
- **접객 톤** 남편이 전부 말함, 다정하고 평범. "아내와 둘입니다, 방 하나면 돼요"
- **요청** 2~3박 / 후불 / 하우스키핑 허용
- **서류 (층1)** 신분증·예약 명단에 **남편 이름만**. 남편은 "아내 것도 있는데…" 하며 못 찾음
- **저녁 신호 (층2)** 직원이 두 사람을 함께 본 기억이 없음. 남편이 "아내 어디 갔지?" 를 접객 중에도 반복
- **야간 신호 (층3)** 새벽에 남편이 프런트로 내려와 아내 행방을 물음. 방에는 1인분 흔적만
- **첫 단서** **체크인 장부에 남편 이름만 적혀 있음**
- **플래그** stay 2, clean 허용, dawnKnock 열어줌
- **배치** 중 / 감염 톤 중간 (남편이 감염일 수도, 아내가 처음부터 없었을 수도)

### #5 젊은 커플
- **외형** 20대 남녀, 캐주얼
- **접객 톤** 함께 왔는데 각자 **다른 방**을 요구, 서로 눈을 안 마주침, 상대 이름을 모름
- **요청** 각 1박 / 각자 결제 / 하우스키핑 무관
- **서류 (층1)** 두 신분증의 사진이 닮았고 생년월일이 하루 차이. 이름은 다름
- **저녁 신호 (층2)** 서로 대화 없음, 남남처럼 행동. 한 명이 "저 사람 아세요?" 라고 물음
- **야간 신호 (층3)** 방 하나에서 **완전히 같은 휴대폰 2개** 발견
- **첫 단서** 청소 중 발견되는 **두 개의 같은 휴대폰**
- **플래그** stay 1 (둘 다), clean 허용, dawnKnock 열어줌
- **배치** 중 / 감염 톤 강함 (둘 중 하나 또는 둘 다)

### #6 장기 투숙객
- **외형** 40~50대 남성, 낡은 티셔츠·츄리닝
- **접객 톤** 며칠 더 연장하러 옴. 현금 뭉치. 방 번호를 자꾸 헷갈림
- **요청** 장기(5박+) / 후불·현금 / 하우스키핑 **극도 거부**, 문밖에 물건을 내놓음
- **서류 (층1)** 처음 체크인 기록과 지금 대는 이름이 미묘하게 다름 (한 글자)
- **저녁 신호 (층2)** "어제 그 얘기 안 했나요?" — 어제와 다른 말을 함
- **야간 신호 (층3)** 방 내부가 날마다 조금씩 달라짐 (가구 위치, 물건 수)
- **첫 단서** 복도에 버려진 **똑같은 물건이 여러 개**
- **플래그** stay 5+, clean **거부**(`allowsMorningCleaning=false`), dawnKnock 열어줌(짜증)

### #7 아이와 온 아버지
