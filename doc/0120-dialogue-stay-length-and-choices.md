### 2. 신규 Question 노드 `stay` — 며칠 묵을지 확인 + 2지선다
허브에 "며칠 묵을지 묻는다/확인한다" 토픽 추가. 답변 1줄 + 선택지 2개 → 각기 다른 반응.

| NPC | 선택지 A → 반응 | 선택지 B → 반응 |
|---|---|---|
| 1 | 하룻밤치 선불 (`stay_pay`) → "...여기요. 딱 하룻밤치." | 나갈 때 정산 (`stay_trust`) → "고맙습니다. 나갈 때 드리죠." |
| 2 | 선불 요구 (`stay_pay`) → "선불이요. 네. 잠깐만 - 잠시만 - " | 나중 정산 (`stay_later`) → "떠날 때요. 좋습니다. 훨씬 나아요." |
| 3 | 규정대로 선불 (`stay_pay`) → (Angry) "선불. 나한테. 어이가 없군..." | 늘 하던 대로 (`stay_skip`) → "현명하군. 계속 그렇게 해." |
| 4 | 하루치씩 (`stay_ok`) → "고마워요. 그게 서로 편하죠." | 정확한 날짜 요구 (`stay_press`) → (Angry) "모른다고 했잖아요..." |
| 5 | 일주일치 한 번에 (`stay_week`) → "고맙구려. 늙은이 마음이 놓이는군." | 하루씩 (`stay_daily`) → "그것도 좋지. 하루하루..." |

- 반응 노드(`Node` role)는 빈 goto → 답변 후 질문 허브로 복귀.
- 숙박 일수는 **대사 플레이버만** — 코드상 추적 안 함 (`GuestManager.CheckIn(npc, room, day)` 그대로). 기간 소진/퇴실 메커니즘은 별도.
