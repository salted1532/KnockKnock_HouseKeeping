# 0103 - 위협 정체성 정리 + 2D NPC 결정

날짜: 2026-08-29

## 요청

1. 직전 대화(몽유병 컨셉의 내적 모순 — 병인데 괴물, 신분증으로 못 잡음, TV 정보 불신)를 정리해 `기획/` 에 문서로.
2. 숙박객 NPC 를 2D 로 만드는 방향에 대한 의견:
   - 접객 모드는 실제 게임에선 ESC 로 못 나감 → 화면 고정 상태라 2D 여도 어색하지 않음
   - 모든 손님 처리 시 새벽으로 자동 전환
   - 객실 문은 못 엶, 노크만 → 문이 살짝 열림 → 화면 고정 → 문틈으로 숙박객 상체만 2D
   - 2D 면 새벽/아침/점심에 돌아다녀도 손님을 직접 마주칠 일 없음 (방 안 / 접객 중에만 조우)

## 결과

`기획/위협의-정체와-판별-설계안.md` 신규 작성. 요지:

- **위협의 정체 = 끝까지 안 밝힘.** "몽유병"은 TV/정부가 붙인 이름일 뿐, 아무도 실체 모름. 설명이 매일 바뀜.
- **판별 = 3층 신호** (서류 / 구별법 대조 / 야간 관찰), 뒤로 갈수록 확실하지만 위험.
- **신분증(SYS-04) 역할 재정의**: 감염이 아니라 *인간의 거짓말*(위조·명단 불일치·진술 모순)을 잡는 별개 축.
- **페이싱**: 저녁 접객 = 약한 판단, **새벽 = 페이오프** (총·정신력으로 되돌릴 수 있음).
- **애매함 유지**: 겁먹은 환자 vs 사람 가죽 — 해소 안 함. 배드엔딩이 암시.
- **숙박객 NPC = 2D 채택.** 모든 조우가 통제된 프레이밍(접객 정위치 / 문틈 상체)이라 2D 약점이 없음. 60명+ 규모, 이미 2D 인 표정 시스템(`NpcData.Portrait`), 몽유병 표식 저작, 공포 톤, PxlCrush 파이프라인 전부 2D 유리.
- **2D 각오할 것 3가지**: 접객 걸어오는 연출(`GuestMover`)은 페이드 등장 or 가려진 채로, 아트 디렉션(빌보드/그림자/픽셀 vs 페인팅) 확정 + 레퍼런스 1명, 디자인 라인 유지(문은 항상 틈만, 자유 카메라 앞에 안 옴, 점프스케어는 전용 에셋).

기존 `핵심컨셉-분석및제언.md`(구별법 3유형·오판·숫자 규칙·메시지)와 중복 안 되게 참조만. 이 문서는 그 위에서 "위협이 뭐고 감지 수단이 실제로 있는가"에 답.
