# 0072 - My/Prefabs 중복 프롭 스캔 (머티리얼 + 지오메트리 기준)

## 요청
Fixtures/Toiletries/Buildings(사용자가 직접 정리 완료)를 제외한 나머지 `Assets/My/Prefabs` 전체에서, 같은 머티리얼을 쓰면서 시각적으로 비슷한(=같은 모델링) 중복 프롭을 찾아 확실한 것은 삭제, 애매한 것은 남겨서 사용자가 직접 확인.

## 조사 / 방법
1. 1차 시도: 메쉬 asset guid만 비교 → 오탐 다수 (같은 FBX 안에 fileID가 다른 서로 다른 서브메쉬가 섞여 있음, 예: `Trees.001`~`.055`).
2. 2차 시도: 버텍스/트라이앵글 개수 + 바운딩박스 크기 비교 → 여전히 오탐 (같은 폴리곤 예산으로 만들어진 서로 다른 나무 변형들이 통계값만 같음).
3. 최종: Unity 에디터 스크립트(`Assets/Editor/Temp_DupeScan.cs`, 임시)로 프리팹마다
   - 재질(머티리얼) guid 조합
   - 실제 버텍스 좌표를 반올림+정렬 후 MD5 해시한 "지오메트리 해시"
   - 버텍스/트라이앵글 개수, 바운딩박스 크기
   를 전수 추출(5,924개 프리팹, Unity 배치 대신 에디터 메뉴 `Tools/Temp Dupe Scan/Export`로 사용자가 직접 실행).
4. **재질 조합이 완전히 같고 + 지오메트리 해시까지 완전히 같은 경우만** "완전히 같은 프롭"으로 분류. 재질은 같지만 해시가 다른 경우는 "애매"로 분류(같은 소품의 미세 변형 등, 예: `Milk_01` vs `Milk_02`).
5. 삭제 후보 3,597개 각각의 guid를 전체 프로젝트(씬 3개 + 모든 프리팹/에셋)에서 참조 여부 재검사 → **씬(`InGame.unity`)과 다른 프리팹(`Motel_room1.prefab`)에서 실제로 쓰이고 있는 5개**를 발견해 삭제 목록에서 제외(보호).

## 결과
- 완전 중복 클러스터: 603개 (같은 재질+같은 지오메트리 해시로 묶임)
- 클러스터에 포함된 프리팹: 4,200개
- 그 중 씬/다른 프리팹에서 참조 중이라 보호: 5개 (`Door_003`, `trash_can_cover`, `trash_can.004`, `Fence.007`, `Carro_su`)
- **최종 삭제 대상: 3,592개** (클러스터당 1개는 남기고, 참조되는 것은 추가로 보존)
- 카테고리별 분포(삭제 후보 기준, 중복 항목 수):
  - Plants_Nature 1,619 / Uncategorized 582 / Food 523 / Furniture 328 / Laundry_Cleaning 227 / Lighting 212 / Kitchen 207 / Buildings_Architecture 191 / Decor 182 / Electronics 49 / Outdoor_Street 34 / Signage 32 / Vehicles 14
- 애매한 경우(같은 재질, 통계는 비슷하지만 지오메트리는 다름): 302쌍 → 삭제하지 않고 목록만 남김 (`doc/0072-ambiguous-pairs.txt`)

## 검증 샘플 (신뢰도 확인용)
- `Food/Drinks_Condiments/Soft_drinks_01.004/.008/.009/...` 등 다수가 완전히 동일한 캔 메쉬+라벨 재질 (실제 asset pack에 같은 캔이 수십 개 복제되어 들어있던 것으로 추정)
- `Plants_Nature/Trees/Tree_03.001~.013`은 완전 동일 클러스터인 반면, 번호가 이어지는 `Tree_0.009,.010,.012,.013`(.011, .014는 다른 클러스터)처럼 **같은 이름 패턴이라도 실제로 다른 지오메트리는 정확히 별도 그룹으로 분리됨** → 탐지 기준이 통계가 아니라 실제 형상을 보고 있다는 증거.
