# 0025 - 기능 정의서 작성

## 날짜
2026-08-17

## 요청 내용
> 넉넉 하우스 키핑 기획을 보고 어떤 기능들이 필요한지 기능 정의서를 작성해보자
> (게임은 경영+공포, 하루 = 아침/점심/저녁/새벽 4개 시간대, 각 시간대별 하루일과→하루일과2(이벤트)→저녁(숙박객 접객)→새벽(자유활동/탐문)→침대(취침, 뉴스/스토리 진행) 흐름.
> 필요 기능으로 1인칭 오브젝트 상호작용, 숙박객 접객 대화(질문 선택+텍스트 출력), 숙박 승인/거절 선택, 신분증 확인 시스템, 객실 배정 UI, 4칸 인벤토리, 상점 UI, NPC 이동/애니메이션(정해진 경로) 등을 언급.

## 처리 내용
코드/에셋 변경이 아닌 순수 문서 작성 요청이라 확인 절차 없이 바로 진행. 새 폴더 `기획/`을 만들어 `기획/기능정의서.md`에 저장.

문서 구성: 게임 개요, 코어 루프 구조(시간대-단계 매핑), SYS-01~12 기능 정의(설명/필요 요소), 데이터 구조 초안(GuestData/RoomData/ItemData/DayData), 추가 검토 제안 기능(세이브, 정산/평판, 이상징후 연출, 엔딩 분기 등), MVP 우선순위 제안.
