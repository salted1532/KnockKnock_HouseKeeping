# 0134 - 모텔 운영 업무 콘텐츠 + 새벽 룸서비스 아이디어 정리

## 요청

사용자가 "미국 소규모 독립 모텔 주인이 직접 다 하는 현실 업무 목록"(프런트·하우스키핑·시설·해충·재고·
외부업체·야간사건·돈, 3단계 난이도: 일반/전문/긴급)을 붙여주고:
1. 이걸 게임(아침/점심/새벽)에 어떻게 써먹을지 아이디어
2. 사용자 제안: 저녁 접객 후 새벽에 주인방 전화로 각 방 요청 확인 → 주인방 창고에서 아이템 픽업 →
   배달하는 이벤트
3. 기획 폴더에 정리

## 결과

`기획/운영-업무-콘텐츠-및-새벽-룸서비스-설계안.md` 신규 작성. 요지:

- **원칙**: 업무는 "정상"의 질감, 공포가 그걸 변형(핵심컨셉 3·4장). 깊이를 위해 업무를 늘리지 않음.
  모든 업무에 일차별 변형. 경제는 생존 보조 수준(핵심컨셉 12장).
- **시간대 배치**: 붙여준 목록 11개 분류를 전부 매핑. 하우스키핑→아침, 시설·외부관리·해충→점심,
  민원·수건요청·야간사건→새벽, 전기/안전→긴급 이벤트, 재고→창고 상시, 돈→취침 정산.
- **점심 "직접 수리 vs 업체 호출"**: 비용/시간/실패확률 트레이드오프. 중반부터 업체 전화 무응답 →
  후반 완전 불가(기존 "경찰 무응답" 장치와 동일). 경제 압박의 척추.
- **새벽 룸서비스 루프 (신규, 핵심)**: 전화(요청 목록) → 창고(4슬롯 픽업, 왕복) → 노크 → 문틈 전달.
  문틈 여는 순간 = 야간 관찰(위협 설계안 층3). 행동력을 탐문과 공유 → "조사 vs 요청" 선택 압박.
  재사용: `KnockEffect`/`doc/0118`, 인벤토리 SYS-07, 행동력 SYS-10. 신규: `DayData` 요청 리스트 +
  전화 Interactable + 창고 픽업 + 배달 판정.
- **공포 훅**: 체크아웃한 방에서 온 요청, 내 목소리 녹음, 새벽엔 다른 창고, 이미 열린 문, 미끼 요청.
- **일차별 변형 표**(초반→중반→후반) 8개 업무.
- **안 하는 것**: 시설 시뮬, 풀 경제, 100개 상호작용화, 배관 퍼즐, 새 매니저.

확인 6개(새벽 루프 우선순위 / 행동력 공유 / 무시 페널티 / 수리 미니게임 여부 / 경제 화면 타이밍 /
분실물 되찾기 방식) 답변 후 새벽 룸서비스 상세 구현 doc으로.
