# 0017. 정리된 산출물 위치를 Assets/My/로 변경

## 날짜
2026-08-06

## 요청 내용
> 내가 사용할 파일들은 My라는 폴더 안에 정리해두려고해 일단 내가 움겨놨는데 다음부터는 My안에다가 만들도록 하자 내가 요청을 잘못했네

사용자가 `Assets/Prefabs/`, `Assets/Materials/`(0016에서 만든 카테고리 폴더)를 직접 `Assets/My/Prefabs/`, `Assets/My/Materials/`로 옮겨둔 상태 확인함(구조는 그대로 유지됨, 41개 폴더씩 정상).

## 순수 Q&A/확인 — 코드 변경 없음
파일 이동은 사용자가 이미 완료해서 제가 따로 할 일은 없음. 앞으로 프리팹/머티리얼 등 정리된 산출물을 만들 때는 `Assets/My/` 밑에 만들도록 메모리에 반영해둠(`project_my-folder-output-location`) — 다음부터 다시 안 여쭤보고 그렇게 하겠음.

## 변경된 파일
없음(사용자가 이미 이동 완료, 메모리만 갱신)
