# 0128 - 대사 한글 번역 검수 (sample.csv 전체)

## 요청
영→한 직역투가 많다. NPC 2 가방 대사 "견본입니다! 대부분 솔이에요" — "솔"이 무슨 말인지 안 통함. 전체 검수 + 이상한 대사 수정.

## 원칙
`text_en` 의미는 유지, `text_ko` 를 자연스러운 구어체로. 캐릭터별 화법 정리:
- NPC 1 나그네 / 2 회사원 / 4 여성 → 존댓말 (접수원 상대)
- NPC 3 거만한 손님 → 반말 (오만)
- NPC 5 노인 → **하오체 통일** (기존에 "되겠지", "좋지", "놓이는군" 등 반말 섞여 있던 것 → "되지 싶소", "좋소", "놓이는구려")
