## 아침의 정체성 제안

**아침 = 지난 밤의 결과를 치우는 시간.** 청소가 척추. 청소·정리 행위 자체를 공포 전달
매체로 삼는다 — 대부분의 방/날은 평범, 가끔 전날 밤 손님·노크·판정과 연결된 이상 징후.
플레이어는 "오늘은 아무 일 없나?" 를 확인하러 도는 것.

## 점심 전환 메커니즘

### 권장: 게시판 = 아침 체크리스트 + 사장 메모, `TasksCompleteCondition` 게이트

지금 게임은 **모든** 단계 전환이 명시적 오브젝트 상호작용이다 (게시판→점심, 테이블→저녁,
침대→아침). 일관성상 아침→점심도 오브젝트 트리거 유지가 맞고, 그 오브젝트는 이미 게시판.

- **태스크 미완료** 로 상호작용 → 남은 할일 목록 표시, **전환 안 함** (`ShowPanelEffect` 패턴).
- **태스크 완료** 로 상호작용 → 사장의 메모(오늘 점심 할 일) 표시 + "일과 종료" 확인 → 전환.
- 오브젝트 하나가 두 역할. 테이블/침대와 완전히 같은 구조.
- 코드: 기존 `PhaseSwitchEffect` + `PhaseCondition` + 게시판 `Interactable` 에 신규
  `TasksCompleteCondition : InteractionCondition` 부착. `IsMet` = 아침 태스크 전부 완료?

### 순수 자동 전환은 비권장

- 공포 게임에서 "안전한" 활동을 끝내고 앞으로 나아가는 건 플레이어가 선택해야 페이싱이 산다.
- 자동 전환은 discovery 도중(방 조사 중, 열쇠 세는 중)에 터질 수 있음 — 페이드가 순간을 끊음.
- "다음으로 넘어갈까" 결정의 순간이 긴장 리듬을 만듦.
- **소프트 유도는 OK**: 마지막 태스크 완료 시 게시판 하이라이트 or 종소리. 여전히 걸어가서 확인.

### 사장방 vs 로비 게시판

통합 — 아침 체크리스트 보드 = 전환 트리거 (하나만). 씬 배치는 디테일이나, "사장방까지
가야 한다 + 사장방이 살짝 불편하다" 가 공포 비트로 좋아서 **사장방 배치 추천**. 메모 자체를
공포 장치로: 어느 날 필체가 이상해짐 / 메모가 없음 / 지시가 말이 안 됨.
