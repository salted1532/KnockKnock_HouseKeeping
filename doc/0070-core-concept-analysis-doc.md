# 0070 - 핵심 컨셉 분석 문서화

날짜: 2026-08-26

## 요청

사용자가 원안(`기획/넉넉하우스키핑.txt`)에 대한 장문의 컨셉 분석/제언(핵심 정체성, 차별화, 구별법 시스템, 오판 시스템, 엔딩 분기, 메시지 재정의 등)을 대화로 제시하고 "해당하는 내용을 참고해서 기획에 문서를 작성해줘"라고 요청.

## 조사

- `기획/넉넉하우스키핑.txt`(원안), `기획/기능정의서.md`(SYS-01~12), `기획/상호작용-미니게임-연동-설계안.md`(기존 설계안 문서 스타일) 확인.
- 기존 기획 문서 스타일(제목 + 개요 줄 + 번호 섹션 + 표)을 따라 신규 문서로 정리.

## 결과

`기획/핵심컨셉-분석및제언.md` 신규 작성. 코드/에셋 변경 없는 순수 기획 문서 작업이라 별도 승인 절차 없이 바로 작성.

주요 내용: 장르 오해 위험, 모텔 공간 활용, 하루 루프의 일차별 변형, 구별법 3유형, 오판 시스템 필요성, 숫자 규칙의 서사적 포장, 대화-판별 연결, 메시지 재정의("불확실한 정보로 타인의 생사를 결정하는 것이 정당한가"), 다중 엔딩 제안, 경제 시스템 비중 축소, 이후 상세 기획 우선순위.

## 변경된 파일

- `기획/핵심컨셉-분석및제언.md` (신규)
